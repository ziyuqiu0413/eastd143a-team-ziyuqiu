# 契紙流年：演示網頁

匹茲堡大學中國土地文書項目的黑客松演示頁，是只在本機運行的靜態網頁。

## 啟動

在項目根目錄（`app/` 的上一層）執行：

```bash
python -m http.server 8765
```

然後打開 <http://localhost:8765/app/>。直接雙擊 `index.html` 打開也可以看到大部分內容，但部分瀏覽器會擋住本地圖像。

## 內容

1. **館藏概覽**：每二十五年的件數（按有無官印分色）、四個時期、地域分布。
2. **憑證譜系**：從清代紅契到 1953 年土改證，共八種憑證，每種配一件館藏原件。
3. **家戶歸戶**：各組的結論和產權事件時間線。「原文」與「推測」用不同樣式區分。
4. **林修枝的九坵地**：直接從原圖按比例裁出的「圖略」，另附地目構成和反推的賦率。
5. **原件對讀**：左邊原圖（點擊放大），右邊轉錄，可切換直排和橫排。

## 數據

頁面數據都在 `app/data.js`，由腳本生成。家戶識讀結果更新後，重新運行：

```bash
python analysis/merge_households.py
```

```bash
python analysis/export_app_data.py
```

圖像從 `../students_documents_export/images/` 讀取，也就是課程提供的圖像包，**不在倉庫裡**。館方標註圖像版權為 Copyright Undetermined，本頁只在本機讀取，請勿把圖像公開發布。

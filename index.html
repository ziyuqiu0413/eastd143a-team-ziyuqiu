研究報告　EASTD 143A 黑客松

一張紙上的國家

匹茲堡大學藏福建土地文書（1584–1978）的初步分析與研究框架

ziyuqiu 組（成員：Ziyu Qiu、Yuting Mei 等）
2026 年 10 月 7 日　資料：University of Pittsburgh Library System, Chinese Land Records

摘要

本研究以匹茲堡大學圖書館藏中國土地文書的館藏元資料（223 件有年代）為基礎，結合一份契尾的逐項判讀，探討國家權力如何進入民間土地交易。我們發現：有官印的文書比例從清代約 63% 上升到 1938 年後的九成以上；館藏地名記錄了閩縣、侯官縣併入閩侯縣等行政變遷；而課程提供的 OCR 雖能辨認人名與地名，卻讀錯了年份、編號與金額這些關鍵數字。最後，我們提出一套可重複使用的記錄框架與省 token 的批量抽取流程，作為後續研究的基礎。

關鍵詞：土地契約、契尾、契稅、紅契與白契、福建、數字人文、OCR 評估

主要發現
  1. 有官印的文書比例隨時代穩定上升：63%、79%、91%、94%，三種計算方式結果一致。
  2. 高恭地契尾（1886）記載的稅銀正好是價銀的 3%，與清代契稅制度吻合。
  3. OCR 在年份、編號、金額上均出錯，年份誤差達六年；關鍵欄位必須人工核對。
  4. 要回答地價、稅率與人際網絡問題，最缺的是價銀、稅銀、中人、代筆四個欄位。

1 研究問題

傳統中國的土地買賣，原本可以只是兩家人之間的一紙私約。官府要求買方繳交契稅、在契約後黏上官方發給的「契尾」，私約才成為受官府承認的「紅契」；沒有經過這道手續的稱為「白契」。

本研究提出三個問題：第一，官府從什麼時候開始、在多大程度上介入這批文書所記錄的交易？第二，一張官方文書如何把國家的要求寫在紙上？第三，以機器讀取這類文書，可靠到什麼程度？

2 資料與方法

資料來源。匹茲堡大學圖書館藏中國土地文書共 220 份（數位館藏分為 235 筆記錄），包括地契、買賣文書、分家書、稅單等，年代從明萬曆十二年（1584）到 1978 年，絕大多數來自福建。課程另提供元資料、館藏指引清單、407 張掃描圖片與 OCR 結果。

資料清理。扣除館藏指引本身及一封非土地文書，得 233 筆；其中 223 筆有年代。跨年代的件有 56 筆，分析時取起始年。地名將「閩邑」「閩邑（縣）」歸入閩縣。

官方性的判定。館藏將每件標為 Government（有地方官府印信）或 Personal（無官印）。我們以此作為「官府介入」的指標，但它是否完全對應傳統的紅契與白契，需要逐件檢驗原件。

分析單位。本研究的比例按館藏的「件」計算。一件可能包含多份文書，詳見第 6 節。

個案判讀。選取高恭地契尾（館藏號 31735064607413），由組員對照原圖逐項判讀，再與課程 OCR、館藏記錄比較。

3 主要發現

3.1 越晚近的文書，越可能蓋有官印

有官印文書的比例，清代約六成，民國前期升到近八成，1938 年以後超過九成。無論以文書的起始年、結束年計算，或只計單一年份的 167 件，趨勢都相同（約 58–63% 升至 89–94%）。

一個合理的解釋是國家對土地交易的登記與課稅越來越深入；但這也可能反映收藏的選擇，例如有官印的文書較易被保存或被收購。

3.2 館藏集中在晚清到民國

數量從 1840 年代起明顯增加，1940 年代最多。這是一批收藏的分布，不能當作福建土地交易量的變化。

3.3 地名記錄了行政區劃的變化

閩縣與侯官縣的記錄大多止於 1913 年前後，之後由閩侯縣取代；林森縣只出現在 1945–1947 年。部分 1913 年以前的文書被標為閩侯縣，可能是編目時採用較晚的地名，提醒我們館藏地名是編目者的判斷，不一定是文書原文。

4 個案：一張契尾

高恭地契尾（光緒十二年，福清縣）是買方繳完契稅後取得的官方憑證。點擊圖中方框，可逐項閱讀原文、白話、英譯與研究意義；虛線框表示判讀尚不確定。

任何契紙都可以拖進下方的框，或按「上傳圖片」。上傳後 AI 會自動判讀一次，標出 5 到 7 個關鍵部位並填寫說明，標為「AI 判讀」；方框位置與文字都需要對照原圖修正。圖片與標注保存在這個瀏覽器裡；要交給組員，請下載專案檔，對方匯入即可。

這張契尾的關鍵在第 8、9 項：價銀約 63.89 兩，稅銀約 1.9167 兩，比例恰為 3%，與清代田房契稅的一般稅率相符。若能在更多文書中抽出這兩個數字，就能檢驗實際稅率是否隨時期與地區而變。

6.4 三條原則

原文與標準化分開存。「光緒拾弍年」與「1886」各佔一欄，不以標準化的值覆蓋原文。每個值都記來源。區分館藏、OCR、AI 與人工判讀，並記錄信心與核對人。不確定就標記。沿用館藏的「？」，另設存疑欄位。

6.5 工作流程與外部標準

AI 或 OCR 初讀並標為未校對，一人對照原圖核對，另一人抽查一成並計算一致率，最後存入 GitHub 的 CSV。日期沿用館藏已採用的 EDTF 格式，年號以中研院「兩千年中西曆轉換」換算；舊縣名對應哈佛 CHGIS 的歷代縣治；圖片以 IIIF 連結館藏原圖。

7 批量抽取流程

407 張圖不可能全部人工讀。我們設計了一個省 token 的 AI 初讀腳本，原則如下：每張圖獨立送出，不在對話中累積上下文；圖片長邊縮至 1200 像素；每件只讀第一頁；只抽第 6 節列為優先的欄位，輸出一行 JSON；第一輪使用較便宜的 Haiku 4.5 模型；輸出長度上限 300 token。所有結果自動標記為「AI 判讀（未校對）」。

建議先跑 10 張並人工核對，計算年份與金額的準確率，再決定是否全跑。這個準確率本身也是研究成果。執行需要 Anthropic API 金鑰，金鑰只能放在環境變數中，不可寫入程式或上傳 GitHub。

查看腳本內容
"""批量抽取契紙關鍵欄位（省 token 版）。

每張圖獨立送出一次請求，只抽欄位、不轉全文，結果寫入 extracted.csv。
已處理過的圖會跳過，可隨時中斷後再續跑。

用法：
  pip install anthropic pillow
  export ANTHROPIC_API_KEY=你的金鑰      # 不要寫進程式，也不要 push 到 GitHub
  python extract.py --limit 10           # 先試 10 張，人工核對
  python extract.py                      # 確認可行再全跑
"""
import argparse, base64, csv, io, json, os, re, sys
from pathlib import Path
from PIL import Image
import anthropic

FIELDS = ["doc_type", "reign_date", "subject", "price", "tax", "middlemen", "scribe", "uncertain"]
PROMPT = """這是一張清代至民國的中國土地文書圖片。只抽取下列欄位，照原文抄錄，不要翻譯、不要解釋。
看不清或沒有的欄位填 null。只輸出一行 JSON，不要任何其他文字：
{"doc_type": 文書類型（如賣契、典契、契尾、稅單、執照）,
 "reign_date": 年月原文（如 光緒拾弍年捌月）,
 "subject": 標的原文（如 店一間、田幾坵、坐落何處）,
 "price": 價銀或價錢原文,
 "tax": 稅銀原文,
 "middlemen": 中人姓名，多人用、分隔,
 "scribe": 代筆人姓名,
 "uncertain": 你沒把握的欄位名稱，用、分隔}"""


def load_image(path, max_side):
    im = Image.open(path).convert("RGB")
    im.thumbnail((max_side, max_side))  # 縮小圖片，token 大致與像素數成正比
    buf = io.BytesIO()
    im.save(buf, "JPEG", quality=85)
    return base64.standard_b64encode(buf.getvalue()).decode()


def parse(text):
    m = re.search(r"\{.*\}", text, re.S)
    return json.loads(m.group(0)) if m else {}


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--images", default="images")
    ap.add_argument("--out", default="extracted.csv")
    ap.add_argument("--limit", type=int, default=0, help="只處理前 N 張（0 = 全部）")
    ap.add_argument("--max-side", type=int, default=1200, help="圖片長邊像素")
    ap.add_argument("--all-pages", action="store_true", help="預設只讀每件的第一頁")
    ap.add_argument("--model", default="claude-haiku-4-5-20251001")
    a = ap.parse_args()

    paths = sorted(Path(a.images).glob("*.jpg"))
    if not a.all_pages:
        paths = [p for p in paths if p.stem.endswith("_001")]
    done = set()
    if os.path.exists(a.out):
        with open(a.out, encoding="utf-8") as f:
            done = {r["image"] for r in csv.DictReader(f)}
    todo = [p for p in paths if p.name not in done]
    if a.limit:
        todo = todo[: a.limit]
    print(f"共 {len(paths)} 張，已完成 {len(done)}，本次處理 {len(todo)}")

    client = anthropic.Anthropic()
    new = not os.path.exists(a.out)
    with open(a.out, "a", newline="", encoding="utf-8") as f:
        w = csv.DictWriter(f, fieldnames=["image", "item_id"] + FIELDS + ["source", "model"])
        if new:
            w.writeheader()
        for i, p in enumerate(todo, 1):
            try:
                r = client.messages.create(
                    model=a.model,
                    max_tokens=300,  # 只要一行 JSON，輸出限短
                    messages=[{"role": "user", "content": [
                        {"type": "image", "source": {"type": "base64", "media_type": "image/jpeg", "data": load_image(p, a.max_side)}},
                        {"type": "text", "text": PROMPT},
                    ]}],
                )
                d = parse(r.content[0].text)
            except Exception as e:
                print(f"[{i}/{len(todo)}] {p.name} 失敗：{e}", file=sys.stderr)
                continue
            row = {k: d.get(k) if not isinstance(d.get(k), list) else "、".join(d[k]) for k in FIELDS}
            w.writerow({"image": p.name, "item_id": p.stem.split("_")[0], **row,
                        "source": "AI 判讀（未校對）", "model": a.model})
            f.flush()
            print(f"[{i}/{len(todo)}] {p.name} {row.get('reign_date')} {row.get('price')}")


if __name__ == "__main__":
    main()

8 研究限制

收藏偏差。這是一批經由購買形成的收藏，年代與地區分布不代表福建全體。分類的意義。Government／Personal 是館藏的編目判斷，與紅契、白契的對應尚待驗證。分析單位。比例按件計算，未區分一件中的多份文書。同名問題。人物分析以名字相同為準，可能把不同的人算在一起。樣本量。個案判讀與 OCR 評估都只基於一張契尾；第 4 節中虛線標示的判讀仍需複核。

9 結論與下一步

這批文書顯示，國家在土地交易中的存在感隨時代增強，而它留下的痕跡就是一張張蓋滿官印、寫明價銀與稅銀的契尾。同時，從紙到數據的轉換並不簡單：機器能讀出名字，卻讀不準數字。

下一步依序是：以記錄表人工判讀 10 至 20 件代表性文書；用這些結果評估 AI 抽取的準確率；再對全部文書抽取價銀、稅銀、中人與代筆，進而分析契稅稅率、地價變化與交易網絡。
